# Product Context

## Why this project exists
Flight schools need a structured system to manage discovery, registration, role approvals, and training lifecycle workflows.

## Problems addressed
- Fragmented onboarding for managers, instructors, and students.
- Lack of role-based approval and access control.
- Operational complexity in course/syllabus/member management.

## User experience goals
- Clear public discovery and onboarding path.
- Predictable role-gated behavior and error messages.
- Admin and manager workflows that are explicit and auditable.

## Primary user groups
- Anonymous visitors
- Registered users
- System admins
- School managers
- Instructors
- Students
