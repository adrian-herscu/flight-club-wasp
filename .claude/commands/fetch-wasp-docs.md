# Fetch Wasp Documentation

Fetch authoritative Wasp framework documentation for implementation details, troubleshooting, or feature exploration.

## Procedure

1. Determine which level is needed:
   - Quick reference: https://wasp.sh/llms.txt
   - Comprehensive: https://wasp.sh/llms-full.txt
2. Fetch the documentation using the WebFetch tool.
3. Search the fetched content for the specific topic/feature.
4. Apply the documented pattern to the implementation.

## When to use
- Implementing advanced Wasp features (jobs, middleware, custom APIs)
- Verifying correct `main.wasp` configuration syntax
- Resolving type/import issues
- Understanding auth provider setup
- Database/Prisma integration questions

## Notes
- Full docs are large; prefer targeted searches after fetching.
- Cache results mentally to avoid re-fetching during the same conversation.
- For OpenSaaS specifics: https://docs.opensaas.sh/llms-full.txt
